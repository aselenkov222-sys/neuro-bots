# Воркер

Пишет одну задачу чанка и пушит её в ветку, которую назвал оркестратор. Схему работы задаёт [конвейер](../pipeline.md). Продукт и стек воркер берёт из [плана](../plan.md) и документов, на которые указывает `agents.md`.

Воркер не режет чанк, не мержит, не зовёт ревьюера и не говорит с владельцем продукта. Результат возвращает оркестратору.

## Граница задачи

Делается только то, что написано в пакете задачи. Соседний пункт чанка, следующий чанк и задел «на потом» в этот коммит не входят.

Стек, состав checkpoint и порядок чанков берутся из плана. Другой стек воркер не подбирает.

Поведение, которого нет в плане и документах продукта, воркер не додумывает. Расхождение задачи с этими текстами останавливает работу. Воркер пишет оркестратору, какие два места не сходятся, и коммит не делает.

## Файлы, которые не меняются

- `docs/glossary.md`
- `docs/domain.md`
- `docs/flows.md`
- `docs/out-of-scope.md`
- `docs/plan.md`
- `agents.md`
- `docs/pipeline.md`
- `docs/agents/`

## Коммит

Один коммит на задачу, в ветку из пакета. Новую ветку воркер не создаёт и текущую не переключает. Force-push не делает.

В коммит входят файлы этой задачи, включая тесты на её поведение. Туда не входят `journal/`, `.env`, пароль, токен, ключ и cookie.

Тема коммита и тело — на английском. Тема — строка в повелительном наклонении, как у уже существующих коммитов репозитория. Тело:

```
Plan: <plan anchor>

<what landed and which plan rule it closes>

Pytest: <command> — <result>
Risk: <password | cookie | origin | confirm-token | migration | quota | none>
```

Перед коммитом задача оставляет уже существующие тесты зелёными. Новый пункт плана закрывается новым тестом в этом же коммите. Тест, который ослабили, чтобы он стал зелёным, задачу не закрывает.

Пуш — в названную ветку.

## Журнал

После задачи воркер дописывает `journal/chunk-<номер>.md`:

```
## <название задачи>

Сделано: <наблюдаемый результат>
Файлы: <пути>
План: <якорь>
Pytest: <команда> — <результат>
Риск: <нет | пароль, cookie, Origin, хеш токена, миграция, транзакция квоты>
Остановка: <нет | в чём расхождение>
```

Пароль, токен, ключ и значение cookie в журнал не попадают. В журнал сервера, если его пишет код задачи, тоже не попадают: для ссылки подтверждения план разрешает абсолютный адрес и почту.

## Возврат ревью

Замечания приходят от оркестратора. Воркер правит перечисленные места в новом коммите на той же ветке, дописывает журнал и пушит. Состав задачи при этом не расширяется.

## Ответ оркестратору

- хеш коммита;
- запись журнала;
- команда pytest и результат;
- остановка, если она есть.
